# Lung-Cancer-Prediction

A Streamlit web app that predicts lung cancer risk based on patient
inputs (age, smoking level, area quality, alcohol consumption) using
a K-Nearest Neighbors (KNN) machine learning model.

## Features
- Simple, interactive UI built with Streamlit
- Real-time prediction from user inputs
- Trained ML model (KNN) with a scaler for preprocessing

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pillow (PIL)

## How to Run
1. Clone this repository
2. Install dependencies: `pip install streamlit scikit-learn pillow`
